# Pokémon Shiny Tracker (CLI)

A simple command-line Python tool to track Pokémon shiny hunt encounters in real time.

## Overview

This project was built as a **practice project** to demonstrate:

- Event-driven input using the `keyboard` library  
- State management and user interaction in a loop  
- Clean terminal output and basic UX design  

It’s a small but functional example of building interactive Python scripts.

## Features
- Keep track of Pokémon to hunt
- Increment or decrement your encounter count with arrow keys
- ESC key to exit gracefully  
- Cross-platform console clearing (`cls` on Windows, `clear` on Unix)

# Why This Project Matters

Although small, this project shows practical coding skills and ability to handle user input and program state. As I continue developing it with features like input validation, a clean GUI, and API functionality, it will serve as a showcase of both technical growth and attention to user experience.

## Usage

1. Install dependencies
   ```bash
   pip install -r requirements.txt
   ```
2. Run the script
   ```bash
   python ShinyTracker.py
   ```
3. Follow on-screen instructions
